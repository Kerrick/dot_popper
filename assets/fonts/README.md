# Fonts

`Fredoka-Bold.ttf` and `Fredoka-SemiBold.ttf` are Fredoka, by Milena Brandão
and Hafontia, under the SIL Open Font License 1.1 (`OFL.txt`, beside them).

They are the static TTFs from https://github.com/hafontia-zz/Fredoka-One at
commit 35c584ff23450c9bcdf8819706e12fcdeefe1712, the upstream commit that
Google Fonts' `ofl/fredoka` cites. Google Fonts ships only the variable
font; Dot Popper uses static instances so every size rasterizes at a fixed
weight.
