# Dot Popper's icon

The files in `icons/` (`icon.icns`, `icon.ico`, and `icon-*.png`) and the
script that draws them, `script/make_icon.rb`, are dedicated to the public
domain under CC0 1.0 Universal (`LICENSES/CC0-1.0.txt`). They were drawn
from code by that script, with no other artwork as their source.

To change the icon, edit the script and run `ruby script/make_icon.rb`
from the repository's root on a Mac (`icon.icns` needs `iconutil`).
